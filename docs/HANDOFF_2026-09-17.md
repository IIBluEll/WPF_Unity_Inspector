## 1. 프로젝트 목적

Unity 빌드가 끝난 뒤 생성되는 BuildReport를 JSON으로 내보내고, 별도의 WPF 프로그램에서 빌드 결과와 포함 Asset을 확인하는 도구입니다.

현재 최소 지원 기준은 Unity 2022.3 이상입니다. 최신 검증 데이터는 Unity 6000.3.20f1에서 생성했습니다.

## 3. 오늘 완료한 작업

### 3.1 Unity Editor 패키지

- Unity 2022.3 이상을 최소 지원 버전으로 설정했습니다.
- 빌드 완료 시 `.unityprojectinspector/build_report.json`을 생성하도록 구성했습니다.
- JSON 계약을 Schema 2로 정리했습니다.
- Unity가 보고한 출력 크기와 실제 빌드 산출물 크기를 분리했습니다.
  - `reportedOutputSizeBytes`: Unity `BuildSummary`가 보고한 값
  - `artifactSizeBytes`: 실제 파일 또는 폴더를 측정한 값
  - `artifactSizeSource`: 크기 산출 기준
- Inspector 자체 로그를 Warning/Error 목록에서 제외했습니다.
- Unity 원본 집계값도 `reportedWarningCount`, `reportedErrorCount`로 보존했습니다.
- 경로에 파일명으로 처리할 수 없는 문자가 포함되어도 예외가 발생하지 않도록 Asset 이름 처리 방식을 보완했습니다.
- 동일한 Asset 경로를 합쳐 중복 없이 기록하도록 정리했습니다.
- `AssetDatabase.GetMainAssetTypeAtPath`를 사용해 `Assets/`와 `Packages/`의 실제 타입을 판별하도록 개선했습니다.
- TextMesh Pro Font Asset이 Material로 분류되던 문제를 수정했습니다.
- 네임스페이스와 Assembly 명칭을 `HM.UnityProjectInspector.Editor`로 통일했습니다.

### 3.2 WPF 분석 도구

- .NET 9 WPF 프로젝트를 구성했습니다.
- Schema 2 JSON과 대응하는 DTO를 작성했습니다.
- `System.Text.Json` 기반 비동기 BuildReport 로더를 작성했습니다.
- 지원 Schema가 아닌 경우 오류를 표시하도록 검증을 추가했습니다.
- 선택한 폴더에 `Assets`, `Packages`, `ProjectSettings`가 있는지 확인합니다.
- `OpenFolderDialog`로 Unity 프로젝트를 선택할 수 있습니다.
- Dashboard에서 다음 값을 표시합니다.
  - 프로젝트명
  - Unity 버전
  - 빌드 결과
  - 플랫폼
  - 실제 산출물 크기
  - 빌드 시간
  - 필터링된 Warning/Error 개수
- Build Analyzer 탭에 읽기 전용 `DataGrid`를 추가했습니다.
- Asset 목록을 `PackedSizeBytes` 내림차순으로 불러옵니다.
- 많은 행을 처리할 수 있도록 행 가상화와 Recycling 모드를 적용했습니다.
- Name, Type, Packed Size, Path 열을 표시하며 열 머리글 정렬을 지원합니다.

주요 파일:

- `Models/BuildReportData.cs`
- `Services/IBuildReportService.cs`
- `Services/BuildReportService.cs`
- `Services/IProjectFileService.cs`
- `Services/ProjectFileService.cs`
- `ViewModels/DashboardViewModel.cs`
- `MainWindow.xaml`
- `MainWindow.xaml.cs`

## 4. 데이터 흐름

```text
Unity Build 완료
    -> BuildPostProcessor 실행
    -> BuildReportExporter가 Schema 2 JSON 생성
    -> Unity 프로젝트/.unityprojectinspector/build_report.json 저장
    -> WPF에서 Unity 프로젝트 폴더 선택
    -> ProjectFileService가 프로젝트와 JSON 경로 검증
    -> BuildReportService가 JSON 역직렬화 및 Schema 검증
    -> DashboardViewModel이 요약과 Asset 목록 구성
    -> Dashboard와 Build Analyzer에 표시
```

## 7. 알아둘 제약과 미검증 항목

- Unity의 `IPostprocessBuildWithReport`는 빌드 후 호출됩니다. 빌드가 시작 전에 취소되거나 매우 이른 단계에서 실패하면 JSON이 갱신되지 않을 수 있습니다.
- `reportedErrorCount`는 Unity 원본 집계이고 `errorCount`는 Inspector 자체 메시지를 제외한 화면용 집계입니다. 두 값이 다를 수 있습니다.
- `reportedOutputSizeBytes`, `artifactSizeBytes`, Asset packed size 합계는 산출 기준이 서로 다르므로 같은 값일 필요가 없습니다.
- Unity 6000.3.20f1의 실제 데이터는 확인했습니다. Unity 2022.3에서의 회귀 테스트는 아직 수행하지 않았습니다.
- Build Analyzer의 XAML 바인딩과 빌드는 확인했습니다. 최신 DataGrid 화면에 2,945개 행이 표시되고 정렬되는지는 실행 화면에서 최종 확인이 필요합니다.
- `DashboardViewModel.cs`의 사용하지 않는 `System.Configuration` using, 공개 setter인 `Platform`, 일부 XAML 들여쓰기는 기능 작업 후 정리할 수 있습니다.
